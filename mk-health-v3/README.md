# mk-health-v3

Professional health tracker scaffold built with Next.js 15, TailwindCSS, Supabase, OpenAI, and Recharts.

## Setup

1. Copy `.env.example` to `.env.local` and add your keys.
2. Install dependencies: `npm install`
3. Run locally: `npm run dev`
4. Build for production: `npm run build`

## Stack

- Frontend: Next.js 15
- UI: TailwindCSS, Lucide Icons, Shadcn-style components
- Database: Supabase PostgreSQL
- Auth: Supabase Auth
- Storage: Supabase Storage
- Charts: Recharts
- AI: OpenAI API
- Hosting: Vercel
